# 🎯 Полное руководство по оптимизации для 1000 кликов/день

## 🚨 Диагноз текущих проблем

**КРИТИЧЕСКАЯ ПРОБЛЕМА**: Ваши браузеры крэшатся из-за **неправильного лимита памяти**:
```yaml
--max-memory-per-child=8000000  # 8MB - это убивает Chrome!
```

Chrome нужно **минимум 200-500MB**, а у вас лимит **8MB** — поэтому Celery убивает каждый браузер через несколько секунд!

## 🔧 Пошаговое исправление

### Шаг 1: Применить оптимизированную конфигурацию

```bash
# Скачать оптимизированные файлы
chmod +x deploy_optimizations.sh

# Применить исправления на сервере
./deploy_optimizations.sh
```

**Что исправляется:**
- ✅ `max-memory-per-child`: 8MB → 500MB
- ✅ `concurrency`: 10 → 4+3 (2 воркера)
- ✅ `max-tasks-per-child`: 2 → 5
- ✅ Добавлен второй search worker
- ✅ Увеличены таймауты для медленных прокси

### Шаг 2: Настроить профили и таргеты

```bash
# На сервере запустить настройку
python3 setup_for_1000_clicks.py
```

**Что настраивается:**
- 🔧 20 оптимизированных профилей (80% desktop, 20% mobile)
- 🎯 Тестовые поисковые таргеты
- ⚙️ Оптимальные системные настройки

## 🔍 Диагностика проблем

### Если браузеры все еще крэшатся:

1. **Проверить лимиты памяти:**
   ```bash
   ssh root@88.99.146.218 'docker logs yandex-maps-bot-celery_yandex_search-1 | grep -i "memory\|killed\|oom"'
   ```

2. **Проверить процессы Chrome:**
   ```bash
   ssh root@88.99.146.218 'ps aux | grep chrome | wc -l'
   # Должно быть 7-10 процессов, не больше 50
   ```

3. **Очистить зависшие процессы:**
   ```bash
   ssh root@88.99.146.218 '/root/yandex-maps-bot/cleanup_chrome.sh'
   ```

### Если медленная работа:

1. **Проверить прокси:**
   - Медленные прокси → замените на более быстрые
   - Много капч → смените pool прокси

2. **Добавить больше воркеров:**
   ```bash
   # В docker-compose.yml
   docker-compose up --scale celery_yandex_search=3
   ```

## 🎛 Тонкая настройка для максимальной производительности

### Если нужно больше 1000 кликов/день:

1. **Увеличить concurrency** (осторожно!):
   ```yaml
   # В docker-compose.yml
   --concurrency=6  # Вместо 4, но следить за памятью
   ```

2. **Добавить третий search worker:**
   ```yaml
   celery_yandex_search_3:
     # Копия celery_yandex_search_2 с именем yandex_search_3
   ```

3. **Уменьшить задержки** (рискованно для капч):
   ```bash
   # В настройках системы
   YANDEX_BOT_MIN_REQUEST_DELAY=5  # Вместо 8
   YANDEX_BOT_MAX_REQUEST_DELAY=10 # Вместо 15
   ```
